# Стиль кода

## Python

### Переменные

Используется `lower_snake_case` для именования переменных. Название переменной не содержит сокращений за исключением установленных ниже.

#### Сокращения для именования переменных виджетов `tkinter`

В начале переменной, содержащей виджет пишется его тип, а затем название через `_`.

- `w` — window
- `l` — label
- `b` — button
- `e` — entry
- `rb` — radio button
- `f` — frame
- `lf` — label frame
- `m` — menu

## Вывод в консоль

Для лучшей читаемости могут использоваться разные цвета для текста.

- **Bright red** (ANSI код 91) — название программы и слово «ОШИБКА».
- **Bright yellow** (ANSI код 93) — важная информация или ссылки.
- **Bright green** (ANSI код 92) — ссылки на другие компоненты программы (модули, библиотеки).
- **Bright cyan** (ANSI код 96) — сообщения \[LOG\].
